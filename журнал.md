- По просьбе пользователя таблицы переделаны в текстовые с рамками (ровные колонки,
  перенос текста внутри ячеек, «да/нет» вместо эмодзи). Генератор — python-скрипт
  в scratchpad сессии; при изменении данных править таблицу вручную или перегенерировать.

- Пользователь выбрал основу: **Twenty** (twentyhq/twenty).
- Создан `модель-данных-twenty.md`: схема связей, стандартные объекты Twenty, 7 новых
  объектов (Объект, Договор, Обследование, Конструктивный элемент, Дефект, Измерение, Прибор),
  workflow-автоматизации, ограничения Twenty (нет генерации PDF, нет офлайна, нет формул),
  порядок внедрения. Типы полей сверены с `FieldMetadataType.ts` в репо Twenty.
  Категории состояния — по ГОСТ 31937, значимость дефектов — по ГОСТ 15467.

- Запуск: Docker на ПК LRK нет → выбрано облако app.twenty.com. Пользователь зарегистрировался,
  пока просто смотрит интерфейс. Автозаведение модели через API (GraphQL /metadata,
  createOneObject/createOneField) — позже, нужен ключ в переменной TWENTY_API_KEY (не в чат).

- **Twenty отклонена** пользователем после просмотра: «очень сложно, непонятно, не человеко-френдли».
  Критерий для следующего выбора: простота интерфейса для не-программиста, желательно русский язык.
  Сущности из `модель-данных-twenty.md` (Объект, Обследование, Дефект…) остаются актуальными
  для любой платформы; привязка к типам полей Twenty — нет.

- **Смена цели:** пользователь хочет найти на GitHub готовое решение именно для обследования
  зданий; если его нет — собрать идеи и писать свою CRM.
  Результат — `готовые-решения-обследование.md` (профильные проекты, смежные системы, 10 идей)
  и `скриншоты/` (Condo, EVALQUAKE, OpenInspection, Twenty). Вывод: готового решения
  под российское обследование (ГОСТ 31937) нет; ближайший аналог — InspectorHub/OpenInspection
  (осмотры домов в США, облачное демо inspectorhub.io). Смежные: Condo (рус., MIT),
  Atlas CMMS (есть русский), EVALQUAKE (мобильная анкета + GPS, evalquake.web.app).
  Перед клонированием любого из них — `/inject`.
- Идеи вынесены в отдельный файл `идеи-для-своей-crm.md`: 15 идей в трёх группах
  (офис / выезд / отчёт) с предварительной пометкой «1-я версия» или «позже».
