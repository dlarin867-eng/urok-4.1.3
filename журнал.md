# Журнал проекта «УРОК 4.1.3 — прога по распознаванию дефекта по фото»

## ▶ С ЧЕГО ПРОДОЛЖИТЬ (обновлено 2026-10-03, ПК LRK)

**Цель проекта:** приложение, которое по фото дефекта здания определяет вид дефекта,
значимость (ГОСТ 15467) и категорию состояния (ГОСТ 31937) и собирает отчёт.
Основа — прототип **SurveyAI** в `прототип-surveyai/`, переведён на Claude.
Что приложение должно уметь — `идеи-для-приложения.md`.

**Где остановились:** прототип переведён на Claude (Anthropic) и проверен без ключа — всё
работает до вызова модели. **Следующий шаг — получить ключ и проверить анализ на настоящем фото.**

**Быстрый старт (на любом ПК):**
1. `git pull` в этой папке (репо `dlarin867-eng/urok-4.1.3-defekt-po-foto`, публичное — секреты не коммитить).
2. `cd прототип-surveyai` → `npm ci` (node_modules не в git).
3. Если нет `.env` (не в git) — скопировать `.env.example` в `.env`, в `APP_API_SECRET_KEY`
   и `VITE_API_SECRET_KEY` вписать одну и ту же случайную строку.
4. Ключ Claude: console.anthropic.com → API Keys → переменная среды пользователя
   `ANTHROPIC_API_KEY` (не в файлы, не в чат) → перезапустить Claude Code / терминал.
5. `npx vite --host 127.0.0.1 --port 5173` → http://127.0.0.1:5173 → загрузить фото дефекта.
   После остановки проверить, что не осталось процессов node/vite.

**Дальше по плану:** промпты под ГОСТ 31937 / рубли / русский язык → провайдер Ollama
(локальный вариант) → отчёт Word/PDF. Полный список — «Осталось сделать» внизу.

**Ключевые файлы:** `идеи-для-приложения.md` (что должно уметь), `прототип-surveyai/ИЗМЕНЕНИЯ.md`
(что поменяли в SurveyAI и как запустить), `прототип-surveyai/netlify/lib/ai-provider.js` (выбор модели).
