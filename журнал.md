# Журнал проекта «УРОК 4.1.3»

## ▶ С ЧЕГО ПРОДОЛЖИТЬ (обновлено 2026-09-29, ПК LRK)

**Цель проекта:** своя CRM для бизнеса по обследованию зданий (ГОСТ 31937). Готового решения
на GitHub нет (Twenty отклонена — сложная). Сейчас учимся на прототипе **SurveyAI**:
фото дефекта → ИИ-анализ → отчёт. Из него берём идеи, код своей CRM пишем сами.

**Где остановились:** прототип `прототип-surveyai/` переведён на Claude (Anthropic) и проверен
без ключа — всё работает до вызова модели. **Следующий шаг — получить ключ и проверить анализ
на настоящем фото.**

**Быстрый старт (на любом ПК):**
1. `git pull` в этой папке (репо `dlarin867-eng/urok-4.1.3`, публичное — секреты не коммитить).
2. `cd прототип-surveyai` → `npm ci` (node_modules не в git).
3. Если нет `.env` (не в git) — скопировать `.env.example` в `.env`, в `APP_API_SECRET_KEY`
   и `VITE_API_SECRET_KEY` вписать одну и ту же случайную строку.
4. Ключ Claude: console.anthropic.com → API Keys → переменная среды пользователя
   `ANTHROPIC_API_KEY` (не в файлы, не в чат) → перезапустить Claude Code / терминал.
5. `npx vite --host 127.0.0.1 --port 5173` → http://127.0.0.1:5173 → загрузить фото дефекта.
   После остановки проверить, что не осталось процессов node/vite.

**Дальше по плану:** промпты под ГОСТ 31937 / рубли / русский язык → провайдер Ollama
(локальный вариант) → выбор стека своей CRM. Полный список — «Осталось сделать» внизу.

**Ключевые файлы:** `идеи-для-своей-crm.md` (что берём в CRM), `модель-данных-twenty.md`
(сущности: Объект, Обследование, Дефект…), `готовые-решения-обследование.md`,
`прототип-surveyai/ИЗМЕНЕНИЯ.md` (что поменяли в SurveyAI и как запустить).

**Что сделано 2026-09-29 (кратко):** обзор CRM на GitHub → Twenty отклонена → поиск готовых
решений (нет) → идеи для своей CRM → развёрнут SurveyAI → переведён с AWS Bedrock на Claude
(модуль `ai-provider.js`, можно переключить на другую модель) → в dev-config переделан хук
автокоммита: теперь коммитит по частям, ищет ключи, пушит на GitHub.
