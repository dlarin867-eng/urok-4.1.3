# Готовые решения для обследования зданий на GitHub

Поиск 2026-09-29 через GitHub API: ~50 запросов на английском и русском (building / home /
property inspection, building survey, snagging, punch list, defect management, site inspection,
condition assessment, обследование зданий, техническое обследование, дефектная ведомость,
технадзор, стройконтроль) и по темам (topics) home-inspection, building-inspection,
construction-management, cmms, facility-management, property-management.
Скриншоты — в папке `скриншоты/`.

## Вывод

Готового решения **под российское обследование зданий (ГОСТ 31937) на GitHub нет**.
По-русски ничего профильного не нашлось. Ближайший работающий аналог — **OpenInspection**
(осмотры домов в США). Остальное — прототипы или заброшенные проекты. Значит: берём идеи и
пишем свою.
