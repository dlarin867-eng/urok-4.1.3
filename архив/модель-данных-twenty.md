# Модель данных CRM обследования зданий на Twenty

Основа — [twentyhq/twenty](https://github.com/twentyhq/twenty). Типы полей сверены
с исходниками (`packages/twenty-shared/src/types/FieldMetadataType.ts`) 2026-09-29.
Все новые объекты и поля создаются в интерфейсе Twenty (Settings → Data model) без
программирования.

## 1. Общая схема

```text
                 ┌──────────────┐
                 │   Company    │ заказчик / собственник
                 └──┬────────┬──┘
          1:N       │        │      1:N
      ┌─────────────┘        └──────────────┐
┌─────┴──────┐   1:1   ┌───────────┐   ┌────┴──────┐
│ Opportunity├────────►│  Договор  │   │  Объект   │
│  (сделка)  │         └─────┬─────┘   └────┬──────┘
└─────┬──────┘               │ 1:N          │ 1:N
      │ N:1                  ▼              ▼
┌─────┴──────┐         ┌──────────────────────────┐        ┌────────────────┐
│   Person   │         │       Обследование       ├───────►│ WorkspaceMember│
└────────────┘         └──┬──────────┬─────────┬──┘  N:1   │   (инженер)    │
                      1:N │      1:N │     1:N │           └────────────────┘
                          ▼          │         ▼
              ┌──────────────────┐   │   ┌───────────┐  N:1  ┌─────────┐
              │ Констр. элемент  │   │   │ Измерение ├──────►│ Прибор  │
              └────┬─────────┬───┘   │   └─────┬─────┘       └─────────┘
               1:N │         └───────┼─────────┘ N:1 (элемент)
                   ▼                 ▼
              ┌────────────────────────┐
              │         Дефект         │  фото, значимость, рекомендация
              └────────────────────────┘
```

