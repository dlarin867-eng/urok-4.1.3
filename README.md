# УРОК 4.1.3 — прога по распознаванию дефекта по фото

Учебный проект: загружаешь фото дефекта здания → ИИ (Claude) определяет вид дефекта,
значимость и состояние конструкции → получаешь отчёт.

Основа — прототип SurveyAI (`iamsameershaik/surveyai-taurgo`, лицензия CC BY-NC 4.0
