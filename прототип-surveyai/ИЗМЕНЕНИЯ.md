# Прототип SurveyAI — что изменено

Основа: [SurveyAI](https://github.com/iamsameershaik/surveyai-taurgo) © 2026 Sameer Shaik,
лицензия **CC BY-NC 4.0** (см. `LICENCE`): только некоммерческое использование, с указанием
автора и изменений. Исходный коммит: `7cfcf61`. Используется как учебный прототип;
в свою CRM переносятся идеи, код пишется заново.

## Изменения (2026-09-29)

- **Модель вынесена в один модуль** `netlify/lib/ai-provider.js` — функция `generate()`.
  Провайдер выбирается переменной `AI_PROVIDER`:
  - `anthropic` (по умолчанию) — Claude, модель `AI_MODEL` (по умолчанию `claude-opus-5-5`),
    глубина рассуждений `AI_EFFORT` (по умолчанию `medium`);
  - `bedrock` — исходный вариант автора (Amazon Nova Pro на AWS Bedrock).
  Локальная модель (Ollama) добавляется сюда же, функции менять не придётся.
- **Fallbacks включены:** если Claude откажется отвечать (срабатывание фильтров
  безопасности), API сам повторит запрос на рекомендованной Anthropic модели.
  Отключить: `AI_FALLBACKS=off`.
- Тип картинки определяется по байтам (страница всегда подписывала файл как JPEG).
- `netlify/functions/bedrock-analyze.js`, `qa.js` — вызывают `generate()` вместо Bedrock;
  понятные сообщения об ошибках (нет/неверный ключ, лимит, отказ модели).
- Лимиты расходов в день: анализ `AI_DAILY_LIMIT` (30), вопросы `AI_QA_DAILY_LIMIT` (100, новый).
- Имена переменных без привязки к Bedrock: `APP_API_SECRET_KEY` (старое
  `BEDROCK_API_SECRET_KEY` тоже работает), `AI_DAILY_LIMIT`.
- `vite.config.ts` — в режиме разработки Vite сам обслуживает `/.netlify/functions/*`,
  `netlify-cli` не нужен. `netlify/package.json` — функции остаются CommonJS.

## Запуск на своём ПК

1. `npm ci` (один раз).
2. Ключ Claude — в переменную среды пользователя `ANTHROPIC_API_KEY`
   (console.anthropic.com → API Keys). В файлы и в чат не писать.
3. `.env` в этой папке (не в git) — скопировать из `.env.example`,
   `APP_API_SECRET_KEY` и `VITE_API_SECRET_KEY` — одинаковая случайная строка.
4. `npx vite --host 127.0.0.1 --port 5173` → http://127.0.0.1:5173

Промпты пока авторские: британские стандарты RICS, цены в фунтах, английский язык.
