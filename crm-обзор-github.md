# Open-source основа для CRM обследования зданий — обзор GitHub

Данные получены через GitHub API (`gh api`) 2026-09-29.
Все репозитории открываются по адресу https://github.com/<Репозиторий>.

- «Verified» — у организации на GitHub стоит галочка проверенного домена.
- `*` смешанная — API вернул NOASSERTION; перед выбором проверить файл LICENSE.

## 3. Специализированно «обследование зданий»

Зрелых решений нет: по запросам «building / property inspection» находятся
исследовательские ML-проекты (0–50 звёзд) или брошенные учебные проекты.
Годятся как будущий модуль «ИИ-распознавание дефектов по фото», не как CRM.
